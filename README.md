# Smart Emergency Sound Recognition Wearable for Hearing Impaired

## Introduction

Smart Emergency Sound Recognition Wearable for Hearing Impaired is an AI-powered wearable assistive system that helps individuals with hearing impairments stay aware of their surroundings by detecting and recognizing important sounds in real time.

The system leverages deep learning techniques for audio classification and integrates with wearable hardware to provide instant feedback through vibrations and visual notifications. By transforming environmental sounds into accessible alerts, the device enhances user safety, awareness, and independence in everyday situations.

## Key Features

* Real-time sound recognition
* Emergency and environmental sound detection
* Deep learning-based audio classification
* Vibration-based notifications
* Visual alerts through an OLED display
* Lightweight and portable wearable design
* Edge-device deployment for real-time inference
